使用文档
维护文档

框架无关

Vue / React / React Native / Ionic 共用同一份 @xapiforge/core。核心库零框架依赖，按运行时选 adapter。

类型安全

swagger.json → TypeScript API 客户端自动生成。openapi-fetch 提供端到端类型推导，路径/参数/响应全类型校验。

鉴权内置

AuthService 单飞 refresh + 窗口保护 + 超时。401 自动刷新 token 并重试，业务代码无感。

多运行时

fetch 可注入。浏览器用原生 fetch，Capacitor 用 capacitorFetch 走原生 HTTP（解决 webview CORS / 证书 / 性能问题）。

middleware 链

内置 auth / retry / httpError 三个内核 middleware。业务侧可加自定义 middleware（如 ABP envelope 解包）。

文件下载

浏览器可按需组装带鉴权和进度的下载封装；Capacitor adapter 提供 downloadFileNative，直接写入原生目录。
