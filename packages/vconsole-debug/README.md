# @xapiforge/vconsole-debug

Framework-agnostic vConsole business diagnostics with masked Storage snapshots and configurable debug actions.

```bash
pnpm add @xapiforge/vconsole-debug
```

The package is configuration-driven so project-specific authentication, routing, and UI behavior stay in the consuming application.

See the [xapiforge repository](https://github.com/gzidou/xapiforge) for examples and source documentation.
