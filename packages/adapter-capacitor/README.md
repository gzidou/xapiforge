# @xapiforge/adapter-capacitor

Capacitor token-storage and native HTTP adapters for `@xapiforge/core`.

```bash
pnpm add @xapiforge/core @xapiforge/adapter-capacitor
```

Install the Capacitor plugins required by the adapter implementation you select in your application. They are intentionally not forced as package peer dependencies.

See the [Ionic and Capacitor guide](https://github.com/gzidou/xapiforge/blob/main/docs/getting-started/ionic-capacitor.md).
