# @xapiforge/core

Framework-agnostic TypeScript HTTP client built on `fetch` and OpenAPI-generated path types.

It provides `createNet`, `HttpClient`, `AuthService`, data-or-throw error handling, retry middleware, request timeouts, and singleflight token refresh.

```bash
pnpm add @xapiforge/core
```

See the [xapiforge repository](https://github.com/gzidou/xapiforge) for browser, Capacitor, React Native, authentication, middleware, and error-handling guides.
